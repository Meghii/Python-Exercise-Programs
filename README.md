# Python Exercise Programs

This repository is where I keep small Python programs while learning the language.

## About

My practice ground for Python fundamentals — variables, loops, conditionals,
functions, collections and basic problem-solving. I add programs as I work
through each topic.

## Topics covered

- Basics: variables, data types, input/output
- Control flow: if/else, loops
- Functions and modules
- Lists, dictionaries, sets, tuples
- File handling
- Basic problem-solving exercises

## How to run

Each program is a standalone `.py` file. Run it with:

```bash
python filename.py
```
